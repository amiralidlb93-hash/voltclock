# ⚡ VoltClock

A modern, neon-inspired clock and time utility built with HTML, CSS, and vanilla JavaScript.

🌐 **Live Demo:** https://amiralidlb93-hash.github.io/voltclock/

---

# 🇬🇧 English

## ✨ Features

- 🕒 Digital clock with 12-hour and 24-hour formats
- 🕰️ Analog clock
- 📅 Persian and Gregorian calendars
- 🌍 World clocks for different time zones
- ⏱️ Stopwatch
- ⏳ Countdown timer
- 🔔 Alarm clock
- 🎨 Multiple neon themes
- 🌐 Persian and English language support
- 🖥️ Fullscreen mode
- 💾 Local storage for user preferences
- 📱 Responsive design for desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- SVG

No frameworks, build tools, or backend services are required.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/amiralidlb93-hash/voltclock.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🌐 GitHub Pages

VoltClock is hosted using GitHub Pages.

**Live Website:** https://amiralidlb93-hash.github.io/voltclock/

## 🔒 Privacy

VoltClock runs directly in your browser. User preferences may be stored locally on your device. No backend server is required.
